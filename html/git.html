Git

  • git status - перечисляет все новые или изменённые файлы, которые нуждаются в фиксации.
  • git add - пндексирует указанный файл для последующего коммита.
  • git commit -m - фиксирует проиндексированные изменения и сохраняет их в историю версий.
  • git branch - создает новую ветку.
  • git mv - перемещает и переименовывает указанный файл, сразу индексируя его для последующего коммита.
